# 页面监控器 (Web Page Monitor)

一个用于监控网页变化的 Chrome 浏览器插件。能够以高频率检测网页内容变化，并发出强力警报。

- **🪟 独立弹窗提醒**：弹出居中的独立窗口，始终在最前面，无论您在干什么都能看到
- **💎 精美界面设计**：渐变紫色背景、流畅动画、现代化 UI

## 核心逻辑：它是如何工作的

该插件通过在后台定期抓取目标网站并对比其内容来工作。

1. **抓取 (Fetching)**: 后台 Service Worker 作为一个独立的代理，每隔 X 秒（可设置 5秒 到 60秒）向目标 URL 发送 HTTP 请求。
2. **清洗 (Cleaning)**: 在对比之前，HTML 会经过清洗。动态元素（如时间戳、脚本标签和随机 Token）会被剔除，以防止误报。
3. **哈希 (Hashing)**: 清洗后的内容被转换为唯一的"哈希值"（数字指纹）。
4. **对比 (Comparison)**: 系统将当前哈希与上一次的哈希进行对比。
   - 如果 **Hash A != Hash B**，意味着页面内容发生了实质性变化。
   - 这将立即触发报警系统。

## 功能特性

### 监控能力
- **高频监控**: 支持快至 5 秒的监控间隔
- **智能过滤**: 自动忽略时间戳等动态内容
- **独立 URL 追踪**: 每个 URL 独立监控，互不干扰

### 三重提醒系统
- **桌面通知**: 系统级通知弹窗
- **声音报警**: 可自定义声音（门铃、成功、警报）和时长（最长 20 秒）
  - 使用 Offscreen Document 技术，100% 可靠
- **独立弹窗**: 居中的独立窗口，始终在最前面
  - 渐变紫色背景，现代化设计
  - 清晰显示变化的页面 URL
  - 支持一键打开或关闭

### 用户体验
- **现代 UI**: 简洁的界面，支持深色模式
- **快捷键支持**: Command/Ctrl + Shift + M 快速添加当前页面
- **自动打开**: 可选自动打开变化的页面

## 安装指南

1. 下载本项目源代码。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的 **"开发者模式"**。
4. 点击 **"加载已解压的扩展程序"** 并选择本项目文件夹。

## 使用方法

1. 点击插件图标打开面板。
2. 输入 URL 并点击 **"添加"**。
3. （可选）在设置中选择你偏好的声音和监控间隔。
4. 插件将在后台运行，你可以关闭面板。

## 技术架构

- **Manifest V3**: 使用最新的 Chrome 扩展标准
- **Offscreen Document**: 可靠的后台音频播放
- **Service Worker**: 高效的后台任务处理
- **独立窗口**: Chrome Windows API 创建置顶提醒
